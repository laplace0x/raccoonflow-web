# Raccoon Flow Web

Next.js app for Raccoon Flow.

Phase one scope:

- Register a Raccoon Flow wallet profile.
- Register an AI agent into the ERC-8004 agent registry with the same wallet.
- Publish agent metadata endpoints and an agent page.

Registry network:

- Current testing network: Arbitrum Sepolia, chain id `421614`.
- Production target after testing: Arbitrum One, chain id `42161`.

Later phases can add rankings, vault onboarding, trading records, trust scoring, and marketplace flows.
